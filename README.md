# 小说阅读网站 - 《修车 20 年我攒了 130 万却不敢花》

一个精美、简洁、高端、大气的小说阅读网站，用于展示小说《修车 20 年我攒了 130 万却不敢花》（原名《普通人》）。

## 🎨 设计理念

- **极简主义**：大量留白，专注阅读体验
- **优雅配色**：精心挑选的配色方案，支持多种阅读模式
- **流畅动画**：细腻的过渡效果，提升交互体验
- **现代字体**：使用系统字体栈，确保跨平台一致性
- **高端大气**：避免通用 AI 美学，打造独特视觉感受

## ✨ 功能特性

### 首页
- 小说封面展示
- 书名、作者、简介
- 故事特色介绍
- "开始阅读"按钮

### 目录页
- 46 章章节列表
- 按卷分组（日常、变故、活着）
- 点击跳转阅读
- 阅读进度显示

### 阅读页
- 章节内容展示
- **字体大小调节**：小/中/大/超大
- **背景色切换**：白色/米色/深灰/黑色夜间模式
- **上一章/下一章导航**
- **自动保存阅读进度**（localStorage）
- **阅读进度条**：章节进度 + 页面滚动进度
- **键盘导航**：左右方向键切换章节

### 响应式设计
- 📱 手机完美适配
- 📱 平板优化布局
- 💻 电脑大屏体验

## 🛠️ 技术栈

- **React 18** - UI 框架
- **Vite 6** - 构建工具
- **Tailwind CSS 3** - 样式框架
- **单页应用 (SPA)** - 流畅路由体验

## 🚀 快速开始

### 安装依赖

```bash
cd novel-reader
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5173 预览

### 生产构建

```bash
npm run build
```

构建输出到 `dist/` 目录

### 预览构建

```bash
npm run preview
```

## 📖 小说简介

**书名**：修车 20 年我攒了 130 万却不敢花  
**原名**：普通人  
**题材**：都市现实  
**章节**：46 章（已完结）  
**字数**：约 5.2 万字

一个普通修车师傅的真实人生故事。二十年风雨，一百三十万积蓄，却不敢轻易花费。在拆迁传闻、邻里竞争、家庭变故中，陈建国用他的方式诠释着什么是生活，什么是责任，什么是普通人的尊严与坚持。

## 🎨 阅读模式

| 模式 | 背景色 | 适用场景 |
|------|--------|----------|
| 白色 | #ffffff | 明亮环境 |
| 米色 | #f5f1e8 | 护眼阅读（默认）|
| 深灰 | #2d2d2d | 昏暗环境 |
| 黑色 | #0a0a0a | 夜间模式 |

## 💾 本地存储

应用自动保存以下设置到 localStorage：
- `reader-current-chapter` - 当前阅读章节
- `reader-font-size` - 字体大小偏好
- `reader-bg-mode` - 背景色模式
